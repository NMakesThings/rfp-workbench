What this page helps with

What this page is for

  • Use it when something looks off: missing workspaces, strange review counts, broken local data, malformed records, or support/handoff questions.
  • It shows what browser-local data exists and whether obvious data-boundary issues are present.

What this page is not

  • This is not part of the normal RFP workflow.
  • It does not repair, delete, reset, migrate, import, restore, or change records.
  • It is not a permissions, audit, security, or production support system.

Safe to use

  • This page is read-only.
  • Diagnostic copy/download includes metadata and counts only, not full client content, source text, public facts, or requirement text.
