Manual prep support

Template Prep Assist

Help prepare client-provided template language for intake by converting document text into clean, structured text or markdown that can be pasted into the Template Text area.

Current intake formats

  • Paste text directly.
  • Load .txt or .md files.
  • Word, PDF, OCR, and direct AI parsing are not included in this v0 pass.

Suggested preparation workflow

  1. Extract or copy text from the client document.
  2. Preserve required client language.
  3. Keep headings and section order.
  4. Mark instructions and placeholders clearly.
  5. Convert to clean text or markdown.
  6. Paste into Template Text.
  7. Run Extract Suggested Sections.
  8. Review and classify sections manually.

After preparing the text, paste it into Template Text, run Extract Suggested Sections, then classify each section.
