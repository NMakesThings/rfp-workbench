Assessment Findings Assist

Paste structured findings JSON for review/import.

What this assist does

  • Generates a copyable external AI prompt.
  • Accepts pasted JSON returned by the external workflow.
  • Validates the pasted JSON and previews draft findings.
  • Imports draft or needs-review findings into this workspace.

What this assist does not do

  • Does not call AI from inside the app.
  • Does not upload or parse documents.
  • Does not verify facts or mutate source records.
  • Does not create final report prose or mark findings Ready.

Source/context checklist

  • Project Intake summary.
  • Client Source Intake notes or document excerpts.
  • Public Research outputs.
  • Project Plan risks, dependencies, and decisions.
  • Consultant notes, known limitations, and assumptions.

CSV import

CSV Import

Import draft findings from a CSV issue log, gap list, or risk register.

Supported v0 format

  • Simple comma-delimited CSV with a header row.
  • Quoted fields and escaped double quotes are supported.
  • Paste CSV text or load a local .csv file.

Review boundaries

  • Imports new Assessment Findings records only.
  • Imported records are Draft or Needs Review only.
  • No source records, project plan items, or requirements are changed.

Not included

  • No Excel workbook parsing.
  • No generic CSV routing to other pages.
  • No automatic dedupe, merge, or Ready status.

Local file

Only .csv files are accepted in this v0. Original file bytes are not stored.
